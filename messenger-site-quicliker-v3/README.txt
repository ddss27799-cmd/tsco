TSMESEDJER + Quik + хаб — один сайт

1. Netlify: загрузите содержимое архива (или подключите репозиторий из Git).
   Функции (netlify/functions) работают только при деплое через Git или Netlify CLI,
   перетаскивание архива в Netlify Drop их не разворачивает.

2. Netlify -> Site configuration -> Environment variables:
     ADMIN_KEY = 241575
   Без этой переменной админ-действия (создать админа, загрузить обновление) закрыты.

3. Админ-панель TSMESEDJER: войдите admin / admin2231 -> меню -> 🛠 Админ-панель.
   - «Ключ администратора» — введите ключ 241575 перед действиями.
   - «Создать админа» — новый логин и пароль получают права администратора.
   - «Обновление сайта (zip)» — загрузите zip с файлами TSMESEDJER (app.html, index.html,
     иконки, manifest, updater.js). Обновление уходит на сервер, все открывшие сайт
     получают новую версию: кэш очищается и страница перезагружается.

Что обновляется через zip: страницы и файлы приложения TSMESEDJER.
Что не обновляется: функции Netlify (бэкенд) и sw.js — их меняют через деплой.
